# 📥 Telegram Group Exporter

Простой локальный инструмент для выгрузки **всей истории сообщений** из группы или
канала Telegram **от лица своего аккаунта**. Всё управляется через страничку в
браузере — редактировать код не нужно.

Результат сохраняется в **JSON** и читаемый **TXT**, опционально скачиваются
**фото и файлы**.

> ⚠️ Используй только для групп/каналов, в которых **состоит твой аккаунт**, и в
> рамках правил Telegram и закона. Это инструмент для личного архива своих чатов.

🔗 **Репозиторий:** https://github.com/amd1138/telegram-group-exporter
За обновлениями возвращайся сюда: **Code → Download ZIP**, либо `git pull`.

---

## Возможности

- Вход по своему аккаунту (Telethon, user-session) — код подтверждения и 2FA-пароль
  прямо в браузере.
- Выгрузка всей истории или последних N сообщений.
- Сохранение в `JSON` (id, дата, автор, текст, reply, media) и в человекочитаемый `TXT`.
- Опциональное скачивание медиа (фото, видео, документы, голосовые) в отдельную папку.
- Не требует знаний программирования — запуск двойным кликом.

---

## Установка и запуск

1. Установи [Python](https://www.python.org/downloads/) (при установке поставь
   галочку **Add Python to PATH**).
2. Двойной клик по **`run.bat`** — он сам поставит зависимости, запустит сервер и
   откроет страницу в браузере (`http://127.0.0.1:5000`).
3. Дальше всё на странице.

> Linux/macOS: `pip install -r requirements.txt && python app.py`, затем открыть
> `http://127.0.0.1:5000`.

---

## Где взять `api_id` и `api_hash`

1. Зайди на [my.telegram.org](https://my.telegram.org) и войди по своему номеру.
2. Открой **API development tools**.
3. Создай приложение (любые название и short name).
4. Скопируй **api_id** (число) и **api_hash** (строка) — впиши их на странице.

---

## Как пользоваться

1. Введи `api_id`, `api_hash` и телефон → **Подключиться**.
2. Введи код из Telegram (и пароль 2FA, если включён).
3. Укажи группу: `@username`, ссылку `https://t.me/...` или числовой id (`-100...`).
4. При желании поставь галочку **«Скачивать фото и файлы»**.
5. **Выгрузить всё** → скачай готовые JSON/TXT, файлы также лежат в папке `exports/`.

---

## Безопасность

- После входа создаётся файл `account.session` — **это ключ от твоего Telegram**.
  Он добавлен в `.gitignore` и **не должен попадать в репозиторий или к другим людям**.
- Передавай проект **без** `account.session` и без папки `exports/`.
