ВЫГРУЗКА СООБЩЕНИЙ TELEGRAM ИЗ ГРУППЫ
=====================================

Проект на GitHub:  https://github.com/amd1138/telegram-group-exporter
Если выйдут обновления — скачай свежую версию оттуда (кнопка Code -> Download ZIP),
или, если знаком с git:  git pull


Что это: качает всю историю сообщений группы от лица твоего аккаунта
и сохраняет в файлы JSON и TXT (папка exports). Всё делается на одной
страничке в браузере — ничего в коде менять не нужно.

КАК ЗАПУСТИТЬ
-------------
1. Нужен установленный Python (https://www.python.org/downloads/,
   при установке — галочка "Add Python to PATH").
2. Двойной клик по файлу  run.bat
3. Откроется страница в браузере. Дальше всё там:
   - где взять api_id / api_hash написано прямо на странице
     (коротко: my.telegram.org -> API development tools);
   - вводишь данные -> код из Telegram -> указываешь группу -> "Выгрузить".
4. Готовые файлы появятся в папке exports и их можно скачать кнопками.

ФОТО И ФАЙЛЫ
------------
- Поставь галочку "Скачивать фото и файлы" перед выгрузкой.
- Они сохранятся в подпапку exports\media_<группа>_<дата>\,
  имя каждого файла начинается с id сообщения.
- В JSON и TXT у сообщения будет ссылка на сохранённый файл (поле "media").
- Это медленнее и занимает место — для больших групп может быть много гигабайт.

ВАЖНО
-----
- Твой аккаунт должен СОСТОЯТЬ в группе, которую выгружаешь.
- Группу можно указать как @username, ссылку t.me/... или числовой id (-100...).
- Файл account.session — это твоя сессия входа. Никому не передавай эту папку
  после входа: по этому файлу можно зайти в твой Telegram.
- Окно с сервером не закрывай, пока работаешь. Закрыл окно = остановил.
